# 🗑️ 쓰레기 — 말로 부리는 휴대폰 비서

이름은 쓰레기지만 일은 열심히 하는 안드로이드 비서 앱입니다.
**인공지능 인증 키도, 돈도 필요 없습니다.** 휴대폰에 원래 들어 있는 음성 인식·글 읽어 주기·글자 인식 기능만 씁니다.

## 할 수 있는 것

| 말하기 예시 | 하는 일 |
|---|---|
| 야 이 쓰레기야 / 야 이 쓰레기야, 유튜브 열어줘 | 앱을 안 열어도 대답하고, 이어서 말한 명령을 실행 ("항상 듣기"를 켜면) |
| 고양이 수명 알려줘 / 대한민국 수도는 어디야 | 구글을 열어서 검색하고, 화면을 읽어서 답을 소리 내어 알려 줌 |
| 유튜브에서 고양이 영상 틀어줘 / 네이버에서 날씨 검색해줘 | 그 사이트에서 검색 |
| 첫 번째 거 눌러줘 / 로그인 눌러줘 | 화면에서 찾아서 대신 누름 |
| 화면 읽어줘 | 지금 화면에 있는 글자를 읽어 줌 |
| 안녕하세요라고 입력해줘 / 엔터 | 입력 칸에 글자를 넣음 |
| 아래로 / 위로 / 뒤로 가 / 홈으로 / 알림창 내려줘 / 화면 캡처해줘 | 화면 이동 |
| 유튜브 열어줘 / 카톡 켜줘 | 앱 실행 |
| 숙제 파일 찾아줘 / 숙제 파일 열어줘 / 메모 파일 읽어줘 / 다운로드 폴더 보여줘 | 파일 찾기·열기·읽기 |
| 5분 타이머 / 아침 7시 알람 / 손전등 켜줘 / 소리 키워 / 와이파이 켜줘 | 휴대폰 기능 |
| 지금 몇 시야 / 오늘 며칠이야 / 배터리 얼마나 남았어 | 바로 대답 |

정해진 말투가 아닌 말은 전부 구글에 물어봅니다.

## 설치하는 법

1. `쓰레기.apk` 파일을 휴대폰으로 옮깁니다.
2. 파일을 누르고, "출처를 알 수 없는 앱 설치"를 허용한 뒤 설치합니다.
3. 쓰레기 앱을 열고 세 가지를 허용합니다.
   - **마이크** — 말 알아듣기
   - **화면 조종** — 접근성 설정에서 "쓰레기 화면 조종"을 켭니다.
     안 켜지면(안드로이드 13 이상): 설정 → 애플리케이션 → 쓰레기 → 오른쪽 위 ⋮ → "제한된 설정 허용"을 누른 뒤 다시 켭니다.
   - **파일 접근** — 파일 찾기·열기
4. 화면에 떠 있는 🗑️ 버튼을 누르면 다른 앱을 쓰는 중에도 부를 수 있습니다. (꾹 누르면 쓰레기 앱이 열립니다.)
5. **"야 이 쓰레기야"로 부르기 (항상 듣기)**를 켜면 앱을 열지 않아도 부르는 소리를 듣고 대답합니다.
   - 듣는 동안에는 안드로이드 규칙 때문에 알림이 계속 떠 있습니다. 알림의 "끄기"로 끌 수 있습니다.
   - 배터리를 더 쓰고, 휴대폰에 따라 듣기를 다시 시작할 때마다 작은 "띵" 소리가 날 수 있습니다.
   - 휴대폰을 껐다 켜면 쓰레기 앱을 한 번 열어 주세요. (안드로이드가 켜질 때 바로 마이크를 쓰는 걸 막습니다.)

안드로이드 8.0 이상에서 설치됩니다. 화면 사진으로 글자를 읽는 기능은 안드로이드 11 이상에서만 됩니다.

## 직접 만들기

```bash
cd assistant-app
./gradlew testDebugUnitTest assembleRelease
# 결과: app/build/outputs/apk/release/app-release.apk
```

안드로이드 개발 도구(플랫폼 35)가 필요합니다. `local.properties`에 `sdk.dir=개발 도구 경로`를 적어 주세요.

## 코드 구조

- `brain/CommandParser.kt` — 말을 알아듣는 두뇌 (안드로이드 없이 시험 가능)
- `brain/AnswerPicker.kt` — 검색 결과 화면에서 답 고르기
- `brain/WakeWord.kt` — "야 이 쓰레기야" 알아듣기
- `WakeService.kt` — 항상 듣기 (앱을 안 열어도 부르면 대답)
- `control/ScreenService.kt` — 화면 읽기·누르기·화면 사진·떠 있는 버튼
- `control/Ocr.kt` — 화면 사진 속 한국어 글자 인식 (휴대폰 안에서 동작)
- `Assistant.kt` — 알아들은 명령을 실제로 실행
- `tools/` — 앱 열기, 파일, 손전등·소리·타이머 같은 휴대폰 기능
